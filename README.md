# Felipe Acosta

### Frontend Developer · Angular & TypeScript

Desarrollo interfaces web con Angular y TypeScript. En mis proyectos trabajo con componentes, navegación, formularios e integración de APIs, desde aplicaciones de descubrimiento musical hasta experiencias de reproducción multimedia en distintas pantallas.

[Proyectos](https://github.com/Piplash?tab=repositories) · [Portafolio: código fuente](https://github.com/Piplash/facosta-portafolio)

## Tecnologías que uso

- **Frontend:** Angular, TypeScript, JavaScript, HTML y CSS.
- **Interfaz:** Angular Material, Bootstrap y componentes reutilizables.
- **Datos y navegación:** RxJS, HttpClient, Angular Router e integración de APIs REST.
- **Herramientas:** Git, npm y Angular CLI.
